- **Field title:** `Couple names (exactly as on the logo)`

## Editing the images

All images are generated from code, so you can change them easily:

1. Edit the text in `src/slides.js`. The `CFG` block at the top sets the proof time and revision count shown across the images.
2. Run `node render.js src/listing.html images` (needs Node + Playwright).
3. The logo designs themselves live in `src/logos.js`.
